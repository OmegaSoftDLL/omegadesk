### Added

- Phase 6 groundwork, library only and not wired into any binary (RMM (remote monitoring and management)): `omegadesk-server::rmm` (`DeviceInventory` with memory/storage utilization ratios, `DriveInventory`, `WindowsUpdateStatus`, and custom fields ported from Remotely `Device.cs`; `SavedScript`, `ScriptingShell`, `RepeatInterval`, `ScriptSchedule`, and `ScriptScheduler` with `run_on_next_connect` offline queueing ported from Remotely `ScriptScheduler.cs` and `ScriptScheduleDispatcher.cs`; `DeploymentLinkManager` per-site expiring HMAC-SHA256 enrollment tokens; `AgentUpdateManager` chunked binary streaming `cmd 10`/`13`/`14` with `taskLimiter` concurrency limiting ported from MeshCentral `meshagent.js`; and `AgentTopic` identity-bound `agent.<device_id>.<channel>` mesh topics) and `omegadesk-policy::rmm_policy` (`resolve_effective_rmm_policy` hierarchical `Tenant -> Site -> Device` policy inheritance, `RmmCheck` + `CheckEvaluator` + `AlertTemplate` failure/resolution actions, and `ScopedRmmRole` with `can_*` `RmmCapabilityFlags`).
- Phase 5 groundwork, library only and not wired into any binary (security, auditing, and PAM): `omegadesk-recording` + `web/src/recording-player.ts` (relay-side append-only `.odrec` binary container with 16-byte big-endian `Type + Flags + Size + TimestampMs` headers ported from MeshCentral `meshrelay.js`, keyframe seek index ported from Guacamole `SessionRecording.js` and `recording.c`, `asciicast` v2 `.cast` terminal recorder, and JumpServer-derived `CommandStorage` with risk classification), `omegadesk-policy::{hujson, posture, mfa, pam}` (`HuJSON` `policy/v2` comment/trailing-comma sanitizer and per-node filter rule compiler ported from Headscale `hscontrol/policy/v2/`, endpoint posture checks for OS version, running EDR processes, country code, and IPv4 CIDR ranges, per-connection RFC 6238 TOTP step-up verification and `BruteForceGuard`, multi-level `AccessTicket` approval workflows ported from JumpServer `apps/tickets/`, priority-ordered `GradedAction` ACLs ported from JumpServer `apps/acls/`, and `LiveSessionController` expiring `ReadOnly`/`ReadWrite` share codes with live lock/terminate ported from JumpServer `sharing.py` and MeshCentral `meshdesktopmultiplex.js`), `omegadesk-session::dlp` (clipboard direction/byte limits, keystroke rate limiter, `redact_bgra_region` screen bounding-box redaction, and dynamic `WatermarkOverlay` ported from KasmVNC DLP), and `omegadesk-identity::vault` (`PBKDF2-HMAC-SHA256` 256-bit Master `KEK` wrapping per-entry random 256-bit `DEK`s via `ChaCha20-Poly1305` with `zeroize` on drop, upgrading Remmina `remmina_crypt.c` and fixing 1Remote `UnSafeStringEncipher.cs`).
- Phase 4 groundwork, library only and not wired into any binary (web dashboard, browser client, and connection manager): `omegadesk-policy` (`Tenant` → `DeviceGroup` → `Device` hierarchy, `UserGroup` memberships, SNI tenant resolution, explicit `AdminRole` separated from `SiteRights` and `MeshRights` bitflags, and 4-layer remote-user consent ported from MeshCentral), `omegadesk-server::web_gateway` + `web/` TypeScript client (WebTransport/WebSocket gateway with Origin/Host validation, per-IP `ConnectionLimiter` and `RequestRateBudget` ported from SubnetDesk, WebCodecs `VideoDecoder` Worker with `OffscreenCanvas`, `vp09.00.10.08`/`avc1.42001f`/`av01.0.04M.08` codec negotiation, Selkies binary framing with `FrameBackpressureGate` per-frame ACK, and noVNC browser `KeyboardEvent.code` to QEMU scancode + X11 keysym mapping including ABNT2 `IntlRo`/`IntlBackslash`), `omegadesk-session::connection_manager` (mRemoteNG folder property inheritance, 1Remote `#tag`/`-#tag` and direct/initials/discrete-subsequence keyword launcher, and `.rdp`, RDCMan `.rdg`, and PuTTY XML importers), `omegadesk-transport::race` (`race_transports_prefer_direct` with 500 ms direct priority window ported from RustDesk), and `omegadesk-codec::video_region` (`VideoRegionDetector` with 500 ms lossless paint-over refresh ported from KasmVNC and Selkies).
- Phase 3 groundwork, library only and not wired into any binary (remote access product): Windows `SYSTEM` service desktop switching (`Winlogon` / UAC Secure Desktop detection via `OpenInputDesktop` / `GetUserObjectInformationW` / `SetThreadDesktop`, RDP session handoff monitor via `WTSGetActiveConsoleSessionId`, `DXGI -> WGC -> GDI` fallback with `BitBlt(..., SRCCOPY | CAPTUREBLT)`, and connection-scoped `WDA_EXCLUDEFROMCAPTURE` privacy mode), `omegadesk-session` (clipboard sync with SHA-256 loop suppression, resumable chunked file transfer with SHA-256 verification, Opus `RESTRICTED_LOWDELAY` 48 kHz profiles, multi-monitor switching, chat, terminal, RustDesk-derived `VideoQosController`, `InvalidateReferenceFrames`, systematic `GF(2^8)` Reed-Solomon FEC, and SubnetDesk-derived mDNS + TOFU serverless LAN handshake), and `omegadesk-quicksupport` (9-digit formatted ID, auto-rotating temporary password after 10 failures, Apollo `PERM` bitflags, and MeshCentral 4-layer remote-user consent).
- Phase 2 groundwork, library only and not wired into any binary (mesh network and coordinator): `omegadesk-noise` (Noise `IK` control channel bound to Ed25519/X25519 device identities), `omegadesk-tun` (validated IPv4/IPv6 packets, `PacketBatch` channel batching, and `InMemoryTun`), `omegadesk-mesh` (sans-I/O connectivity engine with Tailscale-style `disco` hole-punching, 1.5 s relay fallback, and automatic direct-path upgrade), `omegadesk-relay` (stateless DERP-style public-key packet relay with single-use HMAC-SHA256 tickets), and `omegadesk-server` (pre-authorized/ephemeral machine keys, `NetmapBatcher` delta stream, and `*.omega` MagicDNS resolver).
- Automated release workflow (`release-plz` + `git-cliff` + multiplatform archives with `.sha256` sidecars) and OpenSSF Scorecard supply-chain security workflow and badge.
- Per-Monitor V2 DPI awareness (`SetProcessDpiAwarenessContext`), `CapsLock`/`NumLock` toggle state synchronization, `Ctrl+Alt+Del` (`SendSAS` / `Ctrl+Alt+End` shortcut), Windows URO (UDP Receive Segment Coalescing) kill switch in `omegadesk-transport`, Windows low-level keyboard hook (`WH_KEYBOARD_LL`) for `Alt+Tab`/`Alt+Esc`/`LWin`/`RWin`, `AltGr` synthetic `ControlLeft` suppression, fractional scroll accumulation (`ScrollAccumulator`), and aspect-ratio preserving bilinear scaling in `omegadesk-client`.
- Zero-copy D3D11 GPU encoding path in `omegadesk-codec` (`ID3D11VideoProcessor` BGRA→NV12 + `MFCreateDXGISurfaceBuffer` + `IMFDXGIDeviceManager`).
- Hardware cursor capture and compositing (`MONOCHROME`, `COLOR`, `MASKED_COLOR`) and rotated monitor support (`90°`, `180°`, `270°`) in `omegadesk-capture`.
- Hardware H.264 encoding through Media Foundation (Intel Quick Sync, NVIDIA NVENC, AMD AMF), with automatic fallback to OpenH264. Measured 60 fps and 24.5 ms end-to-end latency at 1080p.
- Mandatory access password, generated at every start of the agent.
- Keyframe requests: the client asks for a keyframe after a dropped frame or a decode error.
- Agent and client binaries: DXGI screen capture, QUIC transport with certificate pinning, keyboard and mouse with physical scancodes, latency breakdown in the client title bar.
- Crates `omegadesk-capture`, `omegadesk-codec`, `omegadesk-input` and `omegadesk-transport`.
- Foundation: Rust workspace, CI on Windows, Linux and macOS, dependency license policy (`cargo deny`), `omegadesk-protocol` and `omegadesk-identity`.

### Changed

- The build plan (`docs/plan.md`) and the README no longer mark Phases 2–7 as done. The 2026-11-01 audit found that the crates added for those phases are not used by any binary, that 78 Copilot Code Review findings on PRs #17–#24 were merged without a fix, and that several claims (IronRDP, IddCx driver, MCP server, Linux/macOS capture, SSO/WebAuthn) describe data types rather than working features. Each item now carries an honest status and its known defects.
- `release-plz.toml` covers every workspace crate, so the lockstep version applies to the crates added for Phases 2–7.

### Fixed

- Horizontal mouse wheel direction in the Windows client (`winit` sign inversion relative to `MOUSEEVENTF_HWHEEL`).
- Keys and mouse buttons no longer stay pressed on the remote machine when the session drops or the client loses focus.
- The agent never re-sends an old screen image after losing access to the display (lock screen, UAC).
- The Windows 11 power throttling (EcoQoS) no longer slows the agent down.
